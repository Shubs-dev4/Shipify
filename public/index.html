Shipify Command Bar Guide

How to build, restyle and rebuild a whole site by pasting a script into the command bar, using the AURA script as the worked example.

1. What the command bar is

The command bar is the single line marked with a > prompt at the top of the editor. You type (or paste) JavaScript into it, press Enter, and the page changes. Everything you can do with the mouse, such as adding sections, switching themes or reordering, can also be done with short commands. Because a script is just many commands in a row, one paste can rebuild an entire site.

The bar only appears in the editor. It is hidden in Preview mode.

Keyboard shortcuts

Key What it does
Enter Run the command
Shift + Enter New line (for multi-line commands)
Up / Down Step through your last 50 commands
/ Jump to the command bar from anywhere on the page
Esc Clear what you have typed
Ctrl or Cmd + L Clear the output panel

Results and errors show in the output panel under the bar. Use Hide or the small arrow to collapse it and Clear output to empty it.

Each project has its own command bar, with its own history, output and undo steps.

2. Quick start

Try these one at a time:

help()
clear()
add('hero', {t: 'Hello world', p: 'My first command-built page', b: 'Get started'})
add('features')
theme(2)
sections()

If you do not like the result, type undo().

3. Command reference

Building the page

Command What it does
clear() Removes every section from the current page
clear(true) Removes everything except the header and footer
add(type, options, position) Adds a ready-made section (see section 4)
html(markup, position) Adds your own HTML as a section
code(markup, height, position) Adds a custom code box, which is where scripts and interactive pieces run
remove(i) Deletes the section at position i
move(i, j) Moves the section at position i to position j
sections() Lists every section with its position number

Positions start at 0. If you leave out the position, Shipify places the section sensibly: a header goes to the top, a footer goes to the bottom, and everything else goes just above the footer.

Pages and themes

Command What it does
pages() Lists the pages in the project (the current one has a *)
go('About') Switches to a page by name or number
theme() Lists the themes
theme(3) Switches to a theme by number

The built-in themes are: 0 Mono, 1 Forest, 2 Midnight, 3 Ocean, 4 Sunset, 5 Paper, 6 Violet, 7 Slate, 8 Ink, 9 Noir, 10 Mint, 11 Graphite, 12 Neon, 13 Rose, 14 Lavender, 15 Sky, 16 Sand, 17 Cherry, 18 Lemon, 19 Peach, 20 Sage, 21 Arctic, 22 Coffee, 23 Bubblegum, 24 Dracula, 25 Terminal, 26 Cyber, 27 Emerald Night, 28 Rosewood, 29 Royal, 30 Gold Noir, 31 Charcoal and 32 Ember.

Inspecting and tweaking

Command What it does
qs('h1') Finds the first matching element on the live page
qsa('p') Finds all matching elements
cv The live page itself
print(x) Writes a value to the output panel
cls() Clears the output panel
undo() Undoes the last command
help() Shows a built-in cheat sheet

Anything that is not one of these is treated as plain JavaScript, and await works. For example, qs('h1').textContent = 'Hi' changes the first headline.

4. Ready-made sections with add()

add('hero') creates a section with sample content. Pass an options object to change the text:

In the editor, drag a basic item or section from the left panel onto the page to place it between existing sections. Drag a section by its Drag handle to reorder it. The Basics group includes a text block, button, text field, message box and divider.

add('hero', {t: 'Title', p: 'Paragraph text', b: 'Button label'})
add('text', {}, 2)   // the empty {} keeps defaults; 2 is the position

The available section types are header, hero, herocenter, products, posts, menu, features, team, gallery, pricing, quote, text, cta, contact, signup, legal, code, footer, basictext, basicbutton, textfield, messagebox and divider.

Options that are understood:

Option Used by Meaning
t hero, herocenter, signup, text, cta, legal Title
p hero, herocenter, signup, text, cta Paragraph
b hero, herocenter, signup, cta Button label
br header, footer Brand name
nav header Array of menu links, such as ['Work','Studio','Contact']
cart header true adds a cart button

An unknown type gives an error that lists every valid type, so you can always recover.

5. Your own design with html() and code()

The ready-made sections are quick, but html() and code() are what make a fully custom look possible.

html(): a styled section that matches your site

Use this for anything that should behave like the rest of the page: it uses the page theme, can be edited in place, and sits in the page layout.

  • If your markup is a single element with the class s (for example <section class="s my-hero">), it is added exactly as written.
  • Visible text is editable in place. Click it to open the font, size, weight, left/center/right alignment, text-color, fill, section-color and gradient controls. Explicit contenteditable regions are preserved, and nested editable regions are avoided.
  • Anchors, buttons, role-based controls, styled button-like elements and keyboard-focusable controls can be linked to project pages. Click one in the editor to choose a destination. Its original behavior and styling remain unless you change them.
  • Image elements and the builder's image slots can be clicked to upload, replace or remove an image. Images dropped onto those targets are also accepted. For a custom CSS background-image, add data-builder-image to its element to enable the same controls.
  • Use the section's Design menu to adjust content alignment, navigation alignment, supported link/button styles, hover effects, section background and spacing. Navigation alignment appears for sections with a <nav>.
  • Put your <style> inside the markup. Scope every rule to your own class so it cannot affect other sections.
  • Use the theme colour variables so the section follows theme changes. var(--pb) is the page background and var(--pm) is the muted text colour. The other theme values follow the same naming as the theme list (pf, ps, pa, pt, pl, pr, pfh).

code(): interactive pieces

code(markup, height) places your markup inside a sandboxed frame. Scripts run here, and nowhere else. The frame is intentionally isolated: its text, images and controls cannot use the page editor's text, link, gradient or image tools. Use the section's Edit code button to customize the frame itself. It needs its own full HTML document, CSS and fonts. The height is in pixels and is kept between 40 and 1200 (default 300).

The AURA script uses this for its 3D project carousel: code(`...`, 780).

6. Running a full-site script

  1. Copy the entire script. A partial paste will fail.
  2. Click the command bar (or press /).
  3. Paste, then press Enter. Pasting does not run it until you press Enter.
  4. Read the output panel. A successful script ends by listing the sections it built.
  5. Not happy? Type undo(). A whole script counts as one command, so a single undo reverts everything it did.

Scripts start with clear(), so they replace the page you are on. Anything you typed by hand on that page will be removed. To keep a copy, duplicate the project first or use a fresh page.

Only paste scripts you trust. The command bar runs real JavaScript with access to the whole editor. Treat a script like a program: read it, or get it from someone you know.

7. Worked example: the AURA script

The AURA script (aura-site-command.js) rebuilds the page as a dark, animated studio site. It follows the same pattern any full-site script can use.

Step Code What it does
1 clear(); theme(2); Empties the page and switches to the dark Midnight theme
2 const B = `<style>...</style>` Stores shared styles (gradient text, buttons, chips, animations) in a variable
3 add('header', {br:'AURA', nav:[...]}) Adds a ready-made header with the AURA brand and menu
4 html(`<section class="s au au-hero">${B}...`) Adds the animated hero. ${B} pastes in the shared styles
5 html(...) for the intro heading A short section header, with a scroll-reveal effect
6 code(`<!doctype html>...`, 780) The interactive 3D project carousel, in its own frame, 780px tall
7 html(...) for "How we work" A three-card section with an animated gradient border
8 html(...) for the closing call to action A glowing panel with an email button
9 add('footer', {br:'AURA'}); return sections(); Adds the footer and prints the finished section list

Why the styles repeat in every section

Each section carries its own <style> block (the shared B plus a section-specific one). That keeps every section self-contained, so you can later move() or remove() any of them without breaking the others. Every rule is scoped under .au and a section class such as .au-hero, which stops the styles leaking.

Notes on how it is written

  • Editable HTML sections. Visible text, including the stats and ticker labels, can be formatted with the editor toolbar; the CTA controls can be linked and styled from the section's Design menu. The carousel is a separate code() frame, so customize its contents with Edit code.
  • Responsive layouts. Sizes use clamp() and container units (cqw), and @container rules reflow the layout for narrow widths.
  • Scroll animations. Reveal-on-scroll effects sit inside @supports (animation-timeline:view()), so browsers that lack the feature simply show the content without the animation.
  • Reduced motion. The carousel checks prefers-reduced-motion and stops auto-advancing and tilt effects for people who ask for less motion.
  • Backticks matter. The carousel's own JavaScript uses plain string joining ('<div>'+name+'</div>') rather than template literals. That is deliberate: the carousel code lives inside a backtick string, and a stray backtick or ${...} inside it would end the string early and break the whole script.

9. Writing your own site script

A good template is:

clear();            // start fresh
theme(1);           // pick a theme

add('header', {br: 'My Brand', nav: ['Home', 'About', 'Contact']});
add('hero', {t: 'A big headline', p: 'One supporting sentence.', b: 'Click me'});
html(`<section class="s my-extra">
  <style>.my-extra{padding:80px 48px;background:var(--pb)}</style>
  <h2 contenteditable>My custom section</h2>
  <p contenteditable>Anything you can write in HTML.</p>
</section>`);
add('footer', {br: 'My Brand'});

return sections();  // show the result

Tips:

  • Build in small pieces. Paste a few commands, check the result, then continue.
  • Give each custom section its own class and scope all its CSS to it.
  • Use template literals (backticks) for multi-line HTML, but avoid backticks and ${} inside any code() block.
  • End with return sections(); so you can see what was built.
  • Order matters. Sections are added top to bottom, and add('header') and add('footer') always find their proper place automatically.

10. Troubleshooting

You see Likely cause and fix
The command ends too early. Is a bracket, quote or parenthesis left open? The paste was cut off, or a backtick, bracket or quote is unbalanced. Copy the whole script again
Unknown section "..." Typo in an add() type. The message lists every valid type
No section at position N remove() or move() was given a number outside the page. Run sections() to see valid positions
No page "..." / This project has one page go() needs an existing page name. Run pages() to check
Nothing happens Check you are in the editor, not Preview, then click the bar and press Enter
The page looks wrong after a script Type undo() to go back one step (up to 30 steps are kept per project)
Animations or fonts missing in the carousel The carousel runs in its own frame and loads its own fonts. Check your connection and that the full script was pasted
